# Notatnik śledztwa

Dwa narzędzia do kryminalnych gier planszowych. Działają w przeglądarce, dane zapisują lokalnie.

- [Tablica dowodów](https://marad.github.io/detektyw-notatnik/): graf osób, spraw, miejsc i dowodów z notatkami i tropami.
- [Dziennik śledztwa](https://marad.github.io/detektyw-notatnik/dziennik.html): dni, godziny, stres, miejsca, żetony i zdolności zespołu.
